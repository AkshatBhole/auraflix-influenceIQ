# InfluenceIQ: AI-Powered Influence Rating System

InfluenceIQ is a revolutionary rating system that measures the true influence of public figures based on credibility, longevity, and meaningful engagement rather than just popularity.

## Project Overview

This Streamlit application demonstrates the concept of InfluenceIQ - an AI-powered system that ranks who really matters in the digital world. Unlike traditional metrics that focus on followers and likes, InfluenceIQ evaluates:

- **Credibility & Trustworthiness** - How credible is the person in their field?
- **Fame Longevity** - How long have they remained relevant?
- **Meaningful Engagement** - Are they influencing for the better or just trending for the moment?

## Features

- Introduction page explaining the concept
- Ranking page showing top influencers with filterable results
- Detailed profile pages with multiple metrics:
  - Overall influence score
  - Component scores (credibility, longevity, engagement)
  - AI-powered sentiment analysis
  - Authenticity detection
  - Historical trend visualization
  - Content quality assessment
  - Cross-platform presence analysis

## AI Components

The system leverages several AI techniques:
- Sentiment analysis of public mentions
- Pattern recognition to detect artificial engagement
- Predictive modeling for influence scoring
- Content quality assessment

## Getting Started

### Prerequisites

- Python 3.8+
- Required packages in requirements.txt

### Installation

1. Clone this repository
2. Install required packages:
```
pip install -r requirements.txt
```

3. Run the Streamlit app:
```
streamlit run app.py
```
